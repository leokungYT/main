วิธีใช้ WireGuard แยกจอ (IP ไม่ซ้ำกันแต่ละอีมูฯ)

1. เข้า windscribe.com > My Account > Config Generators > WireGuard
2. เลือกเมือง (คนละเมืองต่อจอ) กด Download ทำซ้ำจนได้ไฟล์เท่าจำนวนจอ
3. เอาไฟล์ .conf ทั้งหมดมาวางในโฟลเดอร์นี้ (wg/)
   จอ MuMu ที่ 0 ได้ไฟล์แรกตามลำดับชื่อ, จอ 1 ได้ไฟล์ที่สอง ...
   ไฟล์น้อยกว่าจอ = วนใช้ซ้ำ (จอนั้นจะได้ IP ซ้ำกัน)
4. configmain.json: "wg_enabled": 1  (0 = ปิด)
   กำหนดเองรายจอได้: "wg_per_device": {"127.0.0.1:16384": "Tokyo.conf"}

ไฟล์ในโฟลเดอร์นี้ไม่ขึ้น GitHub (มีกุญแจบัญชี) ต้องก๊อปไปวางเองทุกเครื่องบอต
