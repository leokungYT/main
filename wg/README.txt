โฟลเดอร์เก็บไฟล์ WireGuard (IP ไม่ซ้ำกันแต่ละอีมูฯ)

วิธีใช้: โยนไฟล์ .conf ที่โหลดจาก Windscribe ลงโฟลเดอร์นี้ได้เลย ไม่ต้องแก้ชื่อ ไม่ต้องแก้อะไร
- แต่ละจอจะ "จอง" ไฟล์ของตัวเอง 1 ไฟล์ ไม่ซ้ำกับจออื่น
- ไฟล์ไม่พอ = จอที่เหลือไม่ต่อ VPN (ไม่ใช้ไฟล์ซ้ำ เพราะกุญแจเดียวกันต่อพร้อมกันจะตีกันเน็ตหลุด)
  -> ควรมีไฟล์ >= จำนวนจอ

โหลดไฟล์: windscribe.com/getconfig/wireguard
  Location = คนละเมืองทุกไฟล์ , Port = 443 , Key Pair = ใช้อันเดิมได้ (สร้างได้สูงสุด 5 อัน)

ปิด/เปิด: configmain.json -> "wg_enabled": 1 (0 = ปิด)

ไฟล์ในโฟลเดอร์นี้ไม่ขึ้น GitHub (มีกุญแจบัญชี) ต้องก๊อปไปวางเองทุกเครื่องบอต ห้ามส่งให้คนอื่น
