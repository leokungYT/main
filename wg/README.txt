โฟลเดอร์เก็บไฟล์ WireGuard (IP ไม่ซ้ำกันแต่ละอีมูฯ)

วิธีใช้: โยนไฟล์ .conf ที่โหลดจาก Windscribe ลงโฟลเดอร์นี้ได้เลย ไม่ต้องแก้ชื่อ ไม่ต้องแก้อะไร
- แต่ละจอจะ "จอง" ไฟล์ของตัวเอง 1 ไฟล์ ไม่ซ้ำกับจออื่น
- ไฟล์ไม่พอ = จอที่เหลือไม่ต่อ VPN (ไม่ใช้ไฟล์ซ้ำ เพราะกุญแจเดียวกันต่อพร้อมกันจะตีกันเน็ตหลุด)
  -> ควรมีไฟล์ >= จำนวนจอ

โหลดไฟล์: windscribe.com/getconfig/wireguard
  Location = คนละเมืองทุกไฟล์ , Port = 443 , Key Pair = ใช้อันเดิมได้ (สร้างได้สูงสุด 5 อัน)

ปิด/เปิด: configmain.json -> "wg_enabled": 1 (0 = ปิด)

ไฟล์ในโฟลเดอร์นี้ไม่ขึ้น GitHub (มีกุญแจบัญชี) ต้องก๊อปไปวางเองทุกเครื่องบอต ห้ามส่งให้คนอื่น

=== สร้างไฟล์อัตโนมัติ (ไม่ต้องโหลดทีละเมือง) ===
โหลดจากเว็บ Windscribe แค่ 1 ไฟล์ (เพื่อเอา Key Pair) วางในโฟลเดอร์นี้ แล้ว:
- เปิดบอตตามปกติ: ถ้าไฟล์น้อยกว่าจำนวนจอ บอทสร้างเพิ่มให้เองจนครบ (config "wg_auto_gen": 1)
- หรือดับเบิลคลิก wg-gen.bat แล้วใส่จำนวนจอ
ไฟล์ที่สร้างคนละเซิร์ฟเวอร์ทั้งหมด (เรียงประเทศใกล้ไทยก่อน) - IP ไม่ซ้ำ ต่อพร้อมกันได้

=== หลายเครื่อง (เช่น 15 จอ x 30 เครื่อง) ===
บัญชีเดียวมี Key Pair ได้ 5 อัน -> แบ่ง: เครื่อง 1-6 = กุญแจ 1, 7-12 = กุญแจ 2, 13-18 = กุญแจ 3, 19-24 = กุญแจ 4, 25-30 = กุญแจ 5
แต่ละเครื่อง:
 1) โฟลเดอร์ wg/ วางแค่ไฟล์ .conf 1 ไฟล์ของกุญแจกลุ่มตัวเอง (ห้ามก๊อป wg/ ทั้งโฟลเดอร์จากเครื่องอื่น)
 2) configmain.json ใส่ "wg_machine": เลขเครื่อง (1-30) และ "wg_per_machine": 15
 3) เปิดบอต -> สร้างไฟล์ช่วงเซิร์ฟเวอร์ของเครื่องนั้นเอง ไม่ชนเครื่องอื่น (ไฟล์ต้นแบบย้ายเป็น keypair.txt)
