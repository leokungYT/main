โยนไฟล์ .conf WireGuard ของ key ชุด "boy" ลงโฟลเดอร์นี้
หรือแยกเป็นโฟลเดอร์ย่อยต่อบัญชีเมล เช่น:
    wg/ip-boy/main-1/   -> บัญชีเมล 1
    wg/ip-boy/main-2/   -> บัญชีเมล 2

สลับใช้ด้วย configmain.json:
    "wg_profile": "ip-boy"           -> ใช้ทั้งโฟลเดอร์ ip-boy
    "wg_profile": "ip-boy/main-1"    -> ใช้เฉพาะโฟลเดอร์ย่อย main-1

ว่าง "" = ใช้ wg_dir เดิม (ค่าปัจจุบัน: wg)

กฎ: 1 โฟลเดอร์ (รวมโฟลเดอร์ย่อย) = 1 บัญชีเมล
    ห้ามผสม keypair จากหลายบัญชีในโฟลเดอร์เดียวกัน
